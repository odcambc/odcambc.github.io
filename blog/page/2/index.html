  • Sanger to fastq

    A quick script to convert ab1 files to fastq

    Sometimes we find ourselves with some Sanger data that we would like to use to prototype an NGS workflow. Here’s a script to turn a list of ab1 files into a single fastq file suitable for that.

    from Bio import SeqIO

# list of ab1 files
files = ["1.ab1", "2.ab1"]

records = []

for file in files:
    record = next(SeqIO.parse(file, "abi"))

SeqIO.write(records, "all_out.fastq", "fastq")

  • Some useful PyMOL defaults

    dot pymolrc

    PyMOL defaults can be set using a .pymolrc file, which can be edited from the “File/Edit pymolrc” menu.

    Here’s mine: mostly taken from Ben McIlwain, a postdoc in Randy’s lab.

    set cartoon_oval_width, 0.2
set cartoon_oval_length, 0.95

set ray_trace_mode,1
set spec_power, 150
set spec_direct,0.1
set ray_shadow,0

set use_shaders, 1
